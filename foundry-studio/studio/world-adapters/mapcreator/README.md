# Map Creator adapter

Foundry owns this bidirectional Map Creator adapter. It ingests authored Map
Creator exports into entity changes, and projects the same entities back into
exactly the accepted file bytes. Repeating an import proposes no changes. Field
accounting and explicit refusals prevent an unhandled field or unsupported file
spelling from disappearing silently.

Run the component and native unit checks from the Foundry repository root:

```sh
python3 studio/world-adapters/mapcreator/check.py \
  --world-proto /absolute/path/to/world-proto \
  --target-dir /absolute/path/to/build-cache \
  --output /absolute/path/to/new-verification-directory
```

The wrapper renders the two `Cargo.toml.in` manifests in a temporary workspace.
`--world-proto` must contain the generic `worldprotocol-core`, adapter SDK/host,
and lens engine. The native-reader compatibility checks use this Foundry checkout's
`sim/site-model`. There is no inferred sibling checkout. The wrapper builds
the current adapter source to WASM before the host checks run, and records the
module hash beside the output artifact. The adapter is optional; this command
does not register it or its vocabulary in a database.

`--production-dumps /absolute/path/to/exports` additionally runs the preserved
ignored production checks. That directory must hold `site-a` through `site-e`.
These private exports are not checked in. Without the option, the synthetic
checks run and the production checks remain explicitly ignored.

| Path | Purpose |
| --- | --- |
| `adapter/src/` | Import, projection, exact formatting, identity lookup, field accounting and refusal behavior. |
| `tests/` | Host tests that exercise the built component, plus the preserved schema derivation helper. |
| `data/seed/application-tests/mapcreator/` | Four authored synthetic exports, reference annotations and the legacy schema baseline. These are test inputs, not WPS snapshots. |
| `data/seed/application/mapcreator/components/` | The 21 definitions generated by the adapter's field tables, with Foundry ownership. |
| `data/seed/application/lenses/mapcreator.worldlens` | The embedded application lens library, one projection per record kind. |

This ownership cut preserves the existing adapter topology and wire behavior.
The older `stitch` representation in its compatibility inputs is not silently
converted to the later traversal-link model. A topology migration must retain
these exact round-trip and refusal checks while separately proving reader behavior.

The original WPS README, design decisions, research, presentations and mixed
application specification are in world-proto's history at commit `2e62d4c`.
